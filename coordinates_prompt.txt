## 🛠️ Quick Technical Recommendations for `html-to-image`

To avoid common pitfalls with `html-to-image` (such as blank images, font pop-in, or low-DPI exports for physical printing):

1. **Set High Resolution (Pixel Ratio):** Pass `pixelRatio: 3` or `4` in the `toPng` options so the generated image is crisp enough for physical A7 printing at 300 DPI:
```typescript
import { toPng } from 'html-to-image';

const dataUrl = await toPng(cardRef.current, {
  pixelRatio: 3, // High DPI export
  cacheBust: true,
});

```


2. **CORS on Avatar Images:** Since user-uploaded photos might be blobs or external URLs, make sure the `<img>` tag for the avatar includes `crossOrigin="anonymous"` so `html-to-image` doesn't throw a taint canvas error.
3. **Font Preloading:** Ensure your custom fonts (like `DejaVuSansMono` or local monospace) are fully loaded before calling `toPng()`, or pass them explicitly in the `fontEmbedCSS` option if fonts appear defaulted in the final export.
